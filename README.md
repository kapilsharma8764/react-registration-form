# React Registration Form

This is a React + Vite registration form project. The form is built with separate `useState` values for each field and logs the submitted form data in the browser console.

## Features

- Responsive registration form design
- Separate state management for each input field
- First name, last name, birthday, gender, email, phone, password, and state fields
- India states and union territories dropdown
- Form submit data shown in console

## Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5173
```

## Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## How To Check Form Data

1. Open the project in the browser.
2. Right-click and choose `Inspect`.
3. Open the `Console` tab.
4. Fill the form and click `Submit`.
5. The form data will appear in the console.
